Функции независимы: исходящий прокси меняет путь от шлюза к поставщику; белый список ограничивает входящие запросы клиентов. Разработка/развёртывание этого выпуска — только экземпляр8843.

Нажмите общую кнопку сохранения конфигурации. Только сохранённый профиль можно проверить.
