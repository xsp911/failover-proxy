# Редизайн Failover Proxy v0.22

## Реализовано

- Постоянная боковая навигация, компактная верхняя панель, контекст раздела и мобильное меню.
- Полностью обновлённая визуальная система всех шести разделов: графитовые поверхности, спокойные акценты, табличные цифры, локальные SVG-иконки, единые формы/таблицы/статусы/dialog/toast/empty/loading.
- Dashboard использует реальные данные. График поддерживает наведение, фокус, стрелки иEscape; нет демонстрационных значений.
- Последние запросы: локальные поиск, статус, сортировка по времени/поставщику/задержке.
- Журнал: локальные поиск, фильтр, сортировка, счётчик и безопасные подробности выбранного события. Открытые подробности не меняются из-за фонового обновления.
- Настройки: сохранены все поля, отдельные секции, write-only ключи, проверки форм/dirty state/ревизий и согласия на опасные действия.
- A6API и Пеликан сохранили все прежние API/paid consent/публикацию/отмену/историю; новый визуальный слой, читаемые таблицы и адаптивные controls.
- Видимый focus, skip link, клавиатурная навигация, Alt+1–6, / для поиска, управляемый focus мобильного меню, reduced-motion.

## Технологии и зависимости

HTML5, CSS Grid/Flexbox/Custom Properties, Vanilla JavaScript, встроенныйSVG. Существующие FastAPI/SQLite сохранены. Никаких React/Vue/Angular, Vite/Webpack, runtime CDN, внешних шрифтов или frontend-сборки. Готовые файлы web/index.html, styles.css, app.js напрямую раздаются Python.

Только для разработки локально установлены ui-ux-pro-max-cli2.15.0 и lucide-static1.61.0, версии/lock вtools/design. Lifecycle scripts отключены при установке; глобальные пакеты не устанавливались. Иконки уже встроены, лицензия сохранена. Skill UI UX Pro Max установлен project-local; frontend-design изучен как рекомендации. Полные Superpowers/Stitch плагины не подключались: первый избыточен, второй требует внешнегоMCP.

Ни npm, ни Node не нужны для запуска самого интерфейса/основногоgateway. Существующий числовой scorer отдельно использует Node; без него функция доступна как unavailable, приложение продолжает запускаться. Опциональный рендер кадров требует Node/Playwright; native Windows рендер явно unavailable до отдельной реализации безопасного process-tree cleanup.

## Совместимость

Добавлен небольшой platform_io адаптер: Linux directory-flock сохраняет прежнее поведение; Windows использует отдельный байтовыйlockfile. Дескрипторные POSIX permissions не выдаются заNTFSACL. ДанныеWindows должны находиться в защищённом пользовательском профиле. Никаких изменений в алгоритмеfailover или AIмаршрутизации.

Launcher tools/run-local.py работает сPath, безопасным отдельным data-dir и первым вводомучётныхданных. Документация docs/RUNNING.md содержитLinux/PowerShell. CI Ubuntu/Windows ×Python3.12/3.14 проверяетплатформеннуюинициализацию/auth/config/staticресурсы; scorer имеетотдельнуюoptionalNodeматрицу.
