Как работают проверки и ограничения

Отбор продавцов бесплатный. Проверка отправляет платные запросы через отдельные тестовые ключи. Fingerprint оценивает сходство с эталоном, не доказывает подлинность. Публикация меняет рабочий маршрут; fallback выключен. Автоматический режим включается только явно.

Как работают автоматизация и бюджеты

Автоматический режим выполняет платные запросы в пределах суточных и разовых бюджетов и изменяет рабочий маршрут этой модели. Для него нужно включить пул. Закрепления (pins) не используются, fallback выключен. Существующие пулы автоматически не включаются.

A6API

PAT и ID аккаунта для Marketplace.

PAT — это пароль консоли. Он даёт доступ к аккаунту, токенам и пинам. Хранится зашифрованным на сервере; в браузере и журналах не сохраняется. Relay-ключ sk-… здесь не подходит.

Учётные данные

ID аккаунта — число из профиля кабинета, не relay-ключ.

Ручная проверка

Не меняет настройки и не включает мониторинг. Обычно 3 платных запроса, максимум 18 с подтверждением и повторами.

Ручная проверка модели

Задания

До 3 поставщиков проверяются параллельно; у одного поставщика — по одному тесту. Прогресс 0–3 относится только к текущему раунду. Низкая оценка требует второго полного раунда. Диагностика содержит счётчики и виды ошибок, без текстов проб.

Журнал проверок

Только изменения определённого статуса; последние 100 записей.
