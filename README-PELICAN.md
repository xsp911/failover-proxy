# Односценный тест «Пеликан»

Отдельная вкладка **Пеликан**. Ровно одна генерация: один пеликан на одном велосипеде, одна непрерывная сцена — солнечная морская деревянная набережная. Формат: самостоятельная SVG-анимация, без HTML/JavaScript и внешних ресурсов.

## Источник идеи

Изучен [w1196396546/manxue-ai](https://github.com/w1196396546/manxue-ai/tree/5da79674417dd0748682f09b7b7467efd1968ea8), коммит `5da79674417dd0748682f09b7b7467efd1968ea8`, Apache-2.0. Использованы архитектурные идеи фиксированного SVG-задания, видимого одноразового кода и отдельной проверки безопасности. Наши Python-модули, англоязычный промпт и интеграция написаны самостоятельно; upstream-сервер не запускается, код репозитория не исполняется. Исходная лицензия и метаданные обзора сохранены в `third_party/manxue-ai/`.

## Запуск и стоимость

Выберите настроенного поставщика, одну upstream-модель и протокол Chat Completions или Responses. Подтвердите будущий платный запрос. Используется зашифрованный ключ уже настроенного поставщика; отдельного публичного ввода ключей нет.

- **Reasoning effort:** по умолчанию поставщика (поле не отправляется), `none`, `minimal`, `low`, `medium`, `high`, `xhigh`. Для Chat Completions передаётся `reasoning_effort`, для Responses — `reasoning.effort`. Поддержка уровней зависит от модели; неподдерживаемое значение не заменяется автоматически и не вызывает повторного платного запроса. Выбор сохраняется в истории. High/xhigh могут увеличить расход reasoning-токенов и оставить меньше бюджета на SVG.
- **300 секунд** общего времени ответа модели, включая SSE; connect до20секунд.
- До **16000 выходных токенов**, при `high`/`xhigh` — **64000**, включая reasoning. Потолок показывается до подтверждения оплаты и сохраняется в запуске. Это верхний предел, не оценка цены. Остановка `length`/`max_output_tokens` сохраняется отдельно как `pelican_output_limit`, вместе с фактическим usage и числом reasoning-токенов, если поставщик его вернул. Исходный текст рассуждений не сохраняется.
- Поток ответа (reasoning, SSE-обёртки и содержимое) ограничен **16 MiB**, независимо от финального SVG (**256 KiB**). Маленькие SSE-чанки могут давать большой транспортный объём — лимит потока не равен размеру рисунка.
- **Одна попытка**, без автоматических повторов и failover на другую модель.
- **Один активный запуск** на весь сервис; отмена прерывает клиентский запрос, но поставщик уже мог начислить оплату.
- Нет расписания, автопроверки, автоматического визуального судьи или дополнительных модельных запросов.
- Интервалы fingerprint и A6API не меняются. Результат не влияет на маршруты, баны или допуск продавцов.

## Локальные кадры и движение

У сохранённого SVG доступна кнопка «Проверить движение · без запроса модели». Повторно используется уже оплаченный рисунок, выполняется только локальный рендер:4PNGкадра480×320 на0/0.5/1/1.5секунды, число видимых SVG-элементов, доли изменившихся пикселей. Результат кешируется вSQLite и читается только администратором. Наличие движения не доказывает качество: анимированный фон также даёт движение. Рисунок, его оценка и баны не изменяются.

Рендерер: Node+Playwright (операторская установка, например FP_PLAYWRIGHT_MODULE с абсолютным путём), отдельная группа процессов, timeout25секунд, один рендер одновременно, ограничение размера ввода/вывода, минимальное окружение без ключей поставщиков. SVG заново проходит allowlist; Chromium offline, сеть/скрипты/ServiceWorker/downloads запрещены. Текущая конфигурация Chromium использует --no-sandbox: это **не ОС-песочница**, остаются риски ошибок браузера/ресурсов. Для усиления изоляции нужен отдельный ограниченный renderer-контейнер/пользователь; не включать произвольный HTML/JS. Отсутствие установленного браузера даёт контролируемую ошибку, не дополнительную генерацию модели.

## Проверка и результат

Проверяются безопасная структура SVG, наличие объявления анимации и одноразового кода в SVG text. Это **не доказывает**, что на картинке именно один пеликан, корректный велосипед или согласованное движение. Качество рисунка и анимации оценивает человек по предпросмотру; автоматическая семантическая оценка в первую версию не входит.

Числовые SMIL-смещения времени, включая отрицательные (`begin="-0.8s"`), разрешены для синхронизации анимации. Событийные триггеры (`click`, `element.click`) и изменение ссылок анимацией по-прежнему запрещены.

Отображение только как `<img>`, никогда вставкой сгенерированной разметки в DOM панели. Серверный валидатор ограничивает элементы/атрибуты/ссылки, размер и сложность XML; SVG-ответ имеет отдельную CSP с `script-src 'none'`, `connect-src 'none'`, `sandbox`, `nosniff`, `no-store`. Изображение доступно только администратору.

Хранятся последние100запусков, не более30дней, в приватной `pelican.db`: статус, время, модель, фактический usage (если есть), структурные проверки и принятый SVG. Ключи, исходный ответ с reasoning и произвольный текст ошибки не сохраняются. После перезапуска незавершённые задания отмечаются прерванными. База входит в online-backup автоматически.
